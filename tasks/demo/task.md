## 示例说明
本文件是引擎自带的**示例任务**，用来演示一份墙报任务是怎么组织的：front-matter 写设置，双井号小标题划分分块，figure 指令声明配图，双星号包住的文字标红。**示例文案与配图均为示意内容**，不代表任何真实数据或结论，可直接整份替换成你自己的素材。

## 素材与方法
<!-- figure: fig_flow_1600x400.png | 图1  工艺流程 ; fig_sample_600x400.png | 图2  样品阵列 -->
一个分块可以配 0 到 3 张图。多张图写在同一行 figure 里、用**分号**分隔，每张各写一条图注；多张会**等高并排**成一条「图条」，宽度按各自的长宽比分配、总宽占满块内可用宽。示例里第一张是 4:1 的宽幅流程条，第二张是 1.5:1 的样品阵列，两者拼在同一个分块里。

## 表征与讨论
<!-- figure: fig_map_800x800.png | 图3  二维分布 -->
排法由一个分块里**图条的整体形态**决定，不是全篇一个规则：宽高比大于 3 的走「文上图下」通栏横幅，小于等于 1.2 的近方图走「文左图右」，其余按分块的宽度定。示例中这一块是近 1:1 的方图，因此正文在左、图在右；它和右边的块并排，各自占一半栏宽。

## 交付与自检
<!-- figure: fig_bars_1200x600.png | 图4  分组响应 -->
改完文案或素材后，先跑一次 python build.py demo 重新构建，再跑一次 python build.py demo --check 让合规清单逐条过一遍；**硬性项全绿（退出码 0）才算可以交付**。清单本身写在 docs/compliance.md 里，加一条要求就必须同时在代码与文档里各写一次，否则测试会红。
